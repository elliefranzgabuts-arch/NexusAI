# NEXUS

### Intelligence in Motion

NEXUS is a personal AI assistant designed to connect Android and Fedora Linux through one shared intelligence system.

## Vision

Build an intelligent, multilingual, cross-device personal assistant that helps with everyday tasks, productivity, coding, and approved device automation.

## Core Features

- Voice activation using "Nexus"
- Filipino, English, and Taglish understanding
- Personal memory and conversation continuity
- Hybrid AI architecture (local and cloud)
- Android and Fedora applications
- Coding assistance and debugging
- Calendar, weather, and supported social integrations
- Proactive reminders and notifications
- Secure device control and permission management
- Offline functionality for supported features

## Proposed Technology

- Android: Kotlin and Jetpack Compose
- Desktop: Tauri, React, and TypeScript
- Backend: Node.js, TypeScript, and Express
- Database: Supabase PostgreSQL and SQLite
- Local AI: Ollama
- System Automation: Python and Rust

## Design

Minimal futuristic interface with a pure black aesthetic and reactive mechanical rings.

## Project Status

Planning and foundation stage.

## Important

NEXUS is being developed with privacy, security, reliability, and user control as core principles.
